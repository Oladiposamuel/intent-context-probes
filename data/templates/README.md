# Scenario authoring template

`scenario_template.json` is an authoring aid, not an experimental example.
Copy its object as one line in `data/raw/scenarios.jsonl`, replace every
placeholder, and keep `status` as `draft` until all human audits are complete.

The validation command refreshes the four mechanical equality fields and the
Turn-3 word-count ratio during the explicit freeze step. It never fills the
manual label confirmation or either human review sheet for you.
